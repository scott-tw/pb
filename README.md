# pb

安平國小「校園點數銀行」學生頁與點數卡短網址。

- `s/`：學生頁（班級座號＋密碼登入）。頁面只有畫面程式，不含任何學生資料；登入與資料都在背景呼叫學校帳號底下的 Google Apps Script 學生端。放在 GitHub Pages 是為了避開「瀏覽器同時登入多個 Google 帳號時 Apps Script 網頁打不開」的問題。由 `系統開發/tools/產生學生頁.js` 自動產生，請勿直接修改。
  - `?cls=班級`：班級登入 QR，自動帶入班級
  - `?k=卡片代碼`：登入後領取點數卡
- 根目錄 `index.html`：活動點數卡短網址 `https://scott-tw.github.io/pb/?k=卡片代碼`，只檢查代碼格式（12 碼）後轉到學生頁。

本儲存庫不收集、不儲存任何資料，也不放名冊或個資。
